> 이거 근데 자율주행은 아니지? 로봇자체에 컨트롤 보드드가 없는데

  네, 정확하게 짚으셨습니다! 현재 구현 상태는 '자율주행(Autonomous Navigation)'이      
  아니며, '원격 조종(Teleoperation) 및 모니터링 시스템' 단계입니다.                    
  ──────                                                                               
  ### 1. 왜 현재 상태가 자율주행이 아닌가요?                                           
                                                                                       
  1. 주행 주체가 '인간(키보드)'임:                                                     
      • 현재 로봇은 스스로 목적지를 설정하고 장애물을 피해 이동하는 것이 아니라,       
      사용자가 키보드(teleop_twist_keyboard)를 눌러 전달하는 /cmd_vel 명령에 의해서만  
      움직입니다.                                                                      
  2. 자율주행 핵심 소프트웨어(Nav2 Stack) 미적용:                                      
      • 주변 지도를 그리는 SLAM (지도 작성)                                            
      • 지도 상에서 본인 위치를 찾는 Localization (위치 추정)                          
      • 장애물을 감지하고 우회하는 Path Planning (경로 계획)                           
      등 자율주행 알고리즘이 전혀 연동되어 있지 않습니다.                              
  3. 주변 거리 센서(LiDAR / Depth Camera) 부재:                                        
      • 현재 장착된 센서는 웹캠(2D 영상)과 IMU 뿐이라 2D/3D 공간 상에서 장애물까지의   
      정확한 거리를 측정할 수 없습니다.                                                
                                                                                       
  ──────                                                                               
  ### 2. "로봇 자체에 컨트롤 보드가 없는데"의 하드웨어 구조적 의미                     
                                                                                       
  현재 로봇의 제어 구조는 하이브리드 분산 구조(Tethered / Remote Host) 형태입니다.     
                                                                                       
  • 로봇 몸체 내부 (Low-level): ESP32만 탑재                                           
      • 역할: 모터 PWM 출력, 엔코더 펄스 카운팅, 서보모터 각도 제어 등 단순 '하드웨어  
      입출력'만 담당 (스스로 판단하는 지능 없음)                                       
  • 외부 컴퓨터 (High-level): Host PC / Jetson
      • 역할: ROS 2 메인 프로세스, AI 비전 알고리즘(ai_vision_node), RViz2 시각화 등   
      무거운 연산을 담당하며 USB 선으로 ESP32와 연결되어 있음
  

  │ 💡 진짜 무선 자율주행 로봇이 되려면?
  │ USB 선으로 PC에 연결된 형태 대신, 로봇 몸체 안에 라즈베리파이 4/5나 NVIDIA Jetson  
  │ Orin Nano 같은 소형 컴퓨터(SBC)를 탑재하고 무선(Wi-Fi)으로 통신해야 완전한 단독    
  로봇
  │ 형태가 됩니다.
  ──────
  ### 3. 향후 이 로버를 '자율주행 로봇'으로 업그레이드하려면?
  
  현재 만들어둔 S.A.R.v1 ROS 2 구조는 자율주행으로 확장하기 위한
  **기반(Foundation)**입니다. 자율주행을 구현하려면 아래 3가지가 추가되어야 합니다:    
  
  1. 센서 추가: 2D LiDAR 센서 또는 Stereo/Depth 카메라 탑재
  2. Nav2 패키지 연동: slam_toolbox로 지도(Map)를 작성하고, ROS 2 Nav2 스택을 붙여 목표
  좌표(Goal Pose) 지정 시 자동 이동 구현
  3. 무선 온보드화: 로봇에 라즈베리파이/Jetson 탑재 후 무선(Wi-Fi) 배터리 구동으로 전환
